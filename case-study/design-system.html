VoiceScribe — Design System

Every screen, control, and state in the product. The whole app uses one font family, four colors, and one shape — a 21px-radius rounded rectangle. Below: the primitives, the components, the screens, and the rationale.

Color

A near-monochrome dark theme. Black background, off-white text, a single accent (the red stop button) that fires only when the app is recording. Green is reserved for live status indicators.

Features & flows

1 · The hotkey

Double-tap Fn within 400 ms to toggle recording. The 400 ms window is short enough to never collide with a single accidental Fn press, and long enough that intentional double-taps don't fail. Works regardless of which app is focused — VoiceScribe never claims keyboard focus itself.

2 · Auto-paste

When transcription finishes, the cleaned text is copied to the system clipboard, then a native helper binary (paste_helper, signed with the app's bundle identifier) sends a Cmd+V. The helper lives inside VoiceScribe.app/Contents/MacOS/ so macOS attributes the keystroke to the app — not to Python — making the Accessibility grant survive OS updates.

3 · AI Polish

Optional. When enabled, the raw Whisper output is sent to a local Ollama model (default llama3.2:3b) with a strict cleaning prompt and 6 few-shot examples. Three guardrails detect failure: chatbot drift ("I'm ready to help…"), over-summarization (output drops >55% of input), and word loss (>30% of input's content words missing). Any of those → fall back to the raw transcript.

4 · Auto dev-mode

The polisher scans every transcript for ~70 dev markers — file extensions said as "dot py", React hooks, git commands, package managers, databases, frameworks. If any fire, it routes to the developer-aware prompt. No setting, no toggle. The model converts "app dot py" → app.py, "use state" → useState, and wraps inline code in backticks.

5 · Custom dictionary

User-added words (proper nouns, company terms, jargon) are joined into a comma-separated string and passed as Whisper's initial_prompt parameter. This biases the acoustic model toward those specific tokens, so brand and people names come through correctly without post-processing.

6 · Snippets

Trigger-phrase expansions, applied after polish but before paste. "intro email" → a full templated message. Match is whole-phrase, case-insensitive, longest-trigger-first so "intro email" beats "intro".

7 · Permission flow

On launch, the app checks AXIsProcessTrustedWithOptions with kAXTrustedCheckOptionPrompt=true, which triggers macOS's native Accessibility prompt if not yet granted. A second check uses AVCaptureDevice.authorizationStatusForMediaType for microphone. Both paths open the relevant System Settings pane on miss, with a rumps.notification explaining what's needed.
